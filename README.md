Описание проекта
Данный проект представляет собой простую реализацию системы управления товарами и категориями.

Классы
Проект включает два основных класса:

# Основные компоненты

- Класс `Product`: хранит информацию о товаре (наименование, описание, цену и количество).
- Класс `Category`: управляет категорией товаров, поддерживает автоматическое обновление общих статистических показателей (количество товаров и категорий).

# Особенности
- Подсчет общего количества созданных категорий.
- Автоматический учет количества товаров при создании новых категорий.
### Использование
Создавайте экземпляры классов `Product` и `Category`, передавая соответствующие аргументы конструкторам. Система автоматически ведет статистику по категориям и товарам.

Пример использования представлен в основном файле проекта.!

## 🚀 Расширенные возможности

### 📱 Новые классы продуктов

#### `Smartphone` (наследник `Product`)
Добавляет специальные характеристики для смартфонов:
- ⚡ Производительность процессора
- 📱 Модель устройства
- 💾 Объем памяти
- 🎨 Цвет корпуса

#### `LawnGrass` (наследник `Product`)
Добавляет параметры для газонной травы:
- 🌍 Страна-производитель
- 📅 Срок прорастания
- 🟢 Цвет травы

### 🔒 Улучшенная функциональность

#### Безопасное сложение товаров
- ✅ Автоматическая проверка типов при операциях
- ➕ Сложение только для одинаковых типов:
  - 📱 + 📱 = ✔️
  - 🌿 + 🌿 = ✔️
  - 📱 + 🌿 = ❌ (вызывает `TypeError`)

#### Защищенное добавление в категории
- 🛡️ Категории принимают только:
  - Базовые товары (`Product`)
  - Их наследников (`Smartphone`, `LawnGrass`)
- 🚫 Попытка добавить посторонний объект → `TypeError`

### ♻️ Совместимость
- 🔄 Полная обратная совместимость с существующим кодом
- ⏮️ Старые сценарии работы без изменений
- 📊 Сохранена автоматическая статистика:
  - 🔢 Общее количество товаров
  - 📂 Общее количество категорий
## 🏗️ Архитектурная основа

### `BaseProduct` - Абстрактный базовый класс
**Гарантирует единый интерфейс:**

#### Обязательные методы:
1. **🆔 Идентификация**
   - `__str__` - единый формат вывода
   - `__init__` - стандартный конструктор

2. **💰 Управление ценой**
   - `price` (property) - чтение/запись с валидацией

3. **➕ Математические операции**
   - `__add__` - сложение товаров

4. **🏭 Фабричный метод**
   - `new_product` - создание из словаря

**Особенности:**
- 🚫 Нельзя создать экземпляр напрямую
- ✅ Все наследники обязаны реализовать методы
- 🔄 Автоматическая проверка при создании классов
